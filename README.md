BLOOM FIT
Fitness & Wellness Mobile App — UI/UX Design
Where your best self takes shape.
BLOOM FIT is a mobile app concept that helps users build healthier habits through daily activity tracking, workout discovery, and clear progress summaries. Its warm, minimal visual style makes the experience feel calm and encouraging.
Project Overview
Designed for Task 4 — Fitness & Wellness App, this project covers the core mobile experience: a home dashboard, workout discovery, progress tracking, and a user profile.
Designer: Donia Said
Tool: Figma
Screen size: 440 × 956 px
Deliverable: Editable UI design and interactive prototype

Screens
Screen	Main features
Welcome / Sign In	BLOOM FIT branding, fitness background, and Google, Apple, and phone sign-in options
Home / Dashboard	Personalized greeting, weekly calendar, training recommendation, daily steps, calories, and active minutes
Explore Workouts	Cardio, Resistance, and Pilates categories; session cards with duration, level, and start controls
Progress	Week, Month, and Year selectors; weekly steps summary, activity chart, completed workouts, and weekly goal
Profile	User information, edit-profile control, fitness goals, daily step target, notifications, settings, and logout


Visual Identity
The design combines warm neutrals, rounded cards, clear typography, and consistent spacing. A flowing double-arc ornament frames the BLOOM FIT wordmark.

Navigation
The bottom navigation connects Home, Workouts, Progress, and Profile, with the current screen highlighted.
- Sign-in controls lead to the Home screen in the prototype.
- Bottom navigation provides direct access to the four core screens.
- Log out returns to the welcome screen.
- For presentation purposes, clicking an empty area advances through the five screens in order and returns to the welcome screen.
Design Goals
- Make daily activity and progress easy to understand.
- Keep the dashboard focused on useful information.
- Encourage consistent activity with goals and short motivational messages.
- Maintain a cohesive visual style across all screens.
- Keep text, cards, icons, and charts editable in Figma.
Prototype Scope
This is a UI/UX prototype, not a functioning mobile application. Activity values, profile details, and workout durations are sample content. Authentication, live tracking, filtering, and settings are visual concepts unless explicitly connected in the prototype.
The current Pilates section includes core stability and recovery stretches. The mobility and stretching photographs can be replaced with more specific Pilates imagery in a future refinement.
